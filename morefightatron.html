With this project we only had one month to work on it. The challenge was trying to set up the game so it does not have many noticable bugs.


Even after I thought I had fixed a bug I came back to work on it the next day and the bug was back again.


To aviod having to go to and change the code later leading to more bugs or wasting time on writing the same code over and over I had to plan ahead and also use functions.


Another problem that I ran into is that I was working with another programmer and he did not use functions or plan ahead, that was a challenge to try to figure out what he was trying to do with the code.


The way I over came this challenge is by slowly looking through the code and testing it, for context. This problem occurred during a long weekend when I was unable to contact this programmer until we returned to school the next week.
